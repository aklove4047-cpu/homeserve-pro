# HomeServe Pro — Home Services Platform

Complete Urban Company–style Home Services & Electronics Repair platform with:
1. **Customer Website** (`website/`) — AC, TV, Mobile, Laptop, Appliances, Electrician, Plumbing, Cleaning, Carpentry, Painting, Pest Control, RO & Chimney.
2. **Admin Panel** (`admin/`) — Live bookings management, technician assignment, service catalog CRUD, revenue & KPIs.
3. **Backend API + SQLite** (`backend/`) — Node.js + Express + built-in `node:sqlite`.
4. **Android App (APK)** (`android-app/`) — Native Kotlin + Jetpack Compose app with offline fallback & live server sync.

## Quick Start (Website + Admin Panel)

Double-click `start.bat` or run:
```powershell
cd backend
npm start
```

- **Customer Website**: http://localhost:4000
- **Admin Panel**: http://localhost:4000/admin
- **Android APK**: `android-app/app/build/outputs/apk/debug/app-debug.apk`
